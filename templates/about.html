Habitat is a House Price Prediction System by AliAdilQ, bringing Python, Django, and machine learning together in one approachable experience.

WHAT'S UNDER THE ROOF

From property details
to a useful estimate.

This portfolio project explores how a regression model can estimate a house price from twelve characteristics: location, living area, rooms, floors, age, parking, property type, furnishing, distance, and nearby amenities.

Django validates each submission, calls a complete scikit-learn pipeline, and stores the result in SQLite. The history and admin panel make those results easy to inspect.
