# Changelog

## v1.0.0 — 2026-10-05

- Initial Django House Price Prediction application, branded Habitat.
- Responsive landing, prediction, result, history, about, and error pages.
- Twelve validated property inputs and persistent, paginated, searchable prediction history.
- Branded Django admin with search, filters, immutable estimate details, and record deletion.
- Reproducible synthetic dataset with 1,600 property records.
- Three regression pipelines compared using cross-validation; selected pipeline evaluated on a separate test set.
- Complete preprocessing/model serialization and recorded training metadata.
- Dataset generation, model training, and idempotent development-only demo seeding commands.
- Chart.js neighborhood visualization and bundled offline frontend dependencies.
- Environment configuration, behavior tests, GitHub Actions, setup instructions, and architecture documentation.
